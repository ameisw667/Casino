## 3 — Ausführungs-Reihenfolge & Commit-Strategie

1. **K0 zuerst** (Hygiene) — sonst laufen alle `git add`-Operationen Gefahr, Artefakte zu erfassen. Vor jedem Commit: `git status --short` gegen die Kohorten-Dateiliste (Appendix §4), niemals `git add .`/`git add -A` — immer explizite Pfade.
2. **Reihenfolge:** K0 → K1 → K2 → K3 → K4 (nach Test-Fix) → K5 → K6 → K7 → K8 (nach typecheck-Fix) → K9.
3. **Commit-Message-Schema:** Conventional Commits, Präfix je Kohorte: `chore:` (K0), `test:`/`fix:`/`chore:` (K1), `feat:`/`perf:` (K2–K7), `docs:` (K9); jede Message nennt die zugehörige Plandatei (z. B. `feat(audio): plan 02 L1–L5 executed`).
4. **Pre-Commit-Hooks:** `.husky/pre-commit` (lint-staged + gitleaks) läuft je Commit; ein Abbruch ist Guardrail, kein `--no-verify`.
5. **Kein Push, kein Merge, kein Rebase** — alle Commits bleiben lokal auf `codex/uncommitted-cohort-review` (K5-Block).
6. **Gemeinsamer Abschluss-Commit K9:** Registrierung des Vorhabens in `worldmap/05_ZUKUNFTSPLANUNG.md` (Zeile 1.46 — dort liegen alle laufenden Plan-Zeilen; die frühere Angabe „Abschnitt Aktive Pläne in worldmap/00" war unzutreffend, ein solcher Abschnitt existiert dort nicht) plus Verweis in `T_REPO_HYGIENE/00_REPO_HYGIENE_UEBERSICHT.md`; danach ist der Plan `🟢 Executed (archiviert)` und wandert in `docs/archive/` in einer Folgeaktion.

**Expliziter Nicht-Scope:** Kein Push (auch nicht `--force`), kein Merge in `main`, keine Remote-DB-Aktionen, keine Migrationen, keine visuelle Selbstbewertung (Jans Screenshots/Sichtprüfungen bleiben sein Gate), keine Änderung an `CLAUDE.md`/`AGENTS.md`, keine Neue-Arbeit an den offenen LCP-Plänen (08, 09, 10, 13).

**Jan-Gates (bewusst auf 3 reduziert):**

1. **G1 nach K0:** Freigabe der Artefakt-Löschung (11k Dateien, regenerierbar) — Einmal-Bestätigung genügt.
2. **G2 nach K4-Test-Fix:** Wenn die Diagnose ein Produktproblem statt Test-Artifakt zeigt → Jan informieren, bevor der Fix geht.
3. **G3 am Ende:** Übersicht der 12 Commits + finaler `git status`-Snapshot; Jan entscheidet über Push/Merge.
