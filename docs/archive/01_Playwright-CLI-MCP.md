## 4. Anforderungen

- Der MCP-Server läuft ausschließlich gegen den lokalen Dev-Server (`http://localhost:3015`), nie gegen Produktion.
- `--isolated` aktiv: kein persistentes Browserprofil auf Disk, kein Risiko einer eingeloggten Produktions-/Wallet-Session über MCP.
- `--allowed-origins` begrenzt auf `localhost:3015` (ggf. plus Supabase-Auth-Redirect, siehe Abschnitt 9) — keine Wildcard-Freigabe.
- Keine echten Wallet-Mutationen (Bet, Cashout, Deposit) über MCP-Interaktionen ohne ausdrückliche Einzelfreigabe.
- Jede schreibende Browser-Aktion (Formular-Submit, Login-Klick) bleibt manuell bestätigungspflichtig — kein automatisiertes Durchklicken kompletter Flows im ersten Pilot.
- Versionsdrift zwischen dem von `@playwright/mcp` gebündelten `playwright-core` (`1.63.0-alpha`) und der Projekt-Testsuite (`1.61.0`) wird dokumentiert und beobachtet, nicht durch ein ungeprüftes Testsuite-Upgrade aufgelöst.
- `.mcp.json` enthält ausschließlich `command`/`args`/Flags — keine Secrets, Tokens oder Zugangsdaten.
- Das Ergebnis des Piloten (Snapshot/Trace eines UI-Fehlers) wird als Testfall in `tests/` abgelegt, nicht nur im Chat dokumentiert.
- Status in der Tabelle oben wird erst nach echtem Nachweis (nicht nach Versuch) von 🔴 auf 🟢 gesetzt.

## 5. Abhängigkeiten

- Lokaler Next.js-Dev-Server muss auf Port 3015 laufen (`npm run dev`), da sowohl `playwright.config.ts` als auch der geplante MCP-Pilot gegen `localhost:3015` zielen.
- Node.js ≥ 18 (offizielle Mindestanforderung von `@playwright/mcp`) — vorhandene Version `v22.16.0` (siehe [`01_Supabase-CLI.md`](01_Supabase-CLI.md) Abschnitt 3) erfüllt das.
- `@playwright/mcp` bringt eine eigene, neuere `playwright-core`-Version mit — eigener Browser-Download über `npx playwright install` kann nötig sein, unabhängig vom bereits für die Testsuite installierten Browser.
- Kein Konflikt zur bestehenden `tests/*.spec.ts`-Suite erwartet, solange der MCP-Pilot nur liest/snapshotted; bei parallelem Lauf ggf. sequenziell fahren (gleicher Port 3015).
- `.mcp.json`-Format muss mit dem verwendeten MCP-Client (Claude Code) kompatibel sein — Format in Abschnitt 3 verifiziert.
