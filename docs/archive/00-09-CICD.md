### M5 — Dependabot-PR-Merge-Routine etablieren ✅ Alle 10 PRs geprüft, Merge-Reihenfolge liegt vor

- **Ziel:** Die 10 offenen PRs werden bewertet und in sicherer Reihenfolge gemerged.
- **Methode:** Jeder PR-Branch in einer isolierten `git worktree` (Scratchpad-Verzeichnis) mit `npm ci && npm run typecheck && npm test && npm run build` geprüft.
- **Methodik-Korrektur während der Ausführung:** Der erste Durchlauf aller 10 Branches parallel erzeugte bei mehreren Branches (`framer-motion`, `@supabase/ssr`, `@supabase/supabase-js`, `@upstash/redis`, `lucide-react`) exakt denselben `next build`-Absturz („Invariant: Expected workStore to be initialized" beim Prerendering von `/_global-error"). Verifiziert per Ausschlussverfahren: (1) derselbe Fehler tritt auch bei einem **solo** Build ohne Parallelität auf → keine Ressourcenkonkurrenz; (2) Kopieren von `.env.local`in die Worktree behebt es nicht → keine fehlenden Env-Vars; (3)`npm run build`auf dem echten`main`-Arbeitsverzeichnis (`V:\VibeCoding\Casino`) läuft **fehlerfrei** durch. Schlussfolgerung: Der Fehler hängt an der Worktree-Umgebung selbst (sehr tief verschachtelter Temp-Pfad unter Windows), nicht an einer der geprüften Dependency-Bumps — betrifft alle 5 betroffenen PRs gleichermaßen unabhängig vom jeweiligen Paket, was gegen einen paketspezifischen Bug spricht. **Konsequenz:** `npm run build`ist mit dieser lokalen Methode nicht zuverlässig pro PR isoliert prüfbar;`npm ci`(Dependency-Auflösung),`npm run typecheck`und`npm test` sind davon nicht betroffen und liefern verlässliches Signal.
