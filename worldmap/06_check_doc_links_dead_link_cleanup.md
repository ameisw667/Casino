## 3 — Umsetzung (Detail zu L1)

**Architekturentscheidung (Jan, Chat 2026-08-30):** Repo-externe Links werden vom Checker übersprungen statt als tot gezählt; der Markdown-Link bleibt für Menschen als Referenz erhalten (keine Textumwandlung, keine Entfernung).

`scripts/check-doc-links.mjs` — neue Abbruchbedingung direkt nach der `KNOWN_EXCEPTIONS`-Prüfung, vor dem `existsSync`-Check:

```js
const normalizedTarget = relative(process.cwd(), targetPath).replace(/\\/g, '/');
if (KNOWN_EXCEPTIONS.has(normalizedTarget)) continue;
if (normalizedTarget === '..' || normalizedTarget.startsWith('../')) {
  externalCount++;
  continue;
}
```

`relative(process.cwd(), targetPath)` liefert einen mit `..` beginnenden Pfad genau dann, wenn das Linkziel die Repo-Wurzel verlässt (z. B. `../../_Brain/50_Library/Secrets-Reference.md` von `xx_sop/` aus). Ein neuer Zähler `externalCount` macht die übersprungenen Treffer in der Abschlusszeile sichtbar (`X repo-externe Verweise übersprungen (nicht prüfbar).`), ohne den blockierenden `liveDeadCount` zu beeinflussen.
