## 📊 1. Executive Summary — Marktposition

Der globale Crypto-Casino-Markt überschreitet 2026 die **$65 Milliarden**-Marke (CAGR ~12–15%).

**Casino Royale heute:** Ein vollständig spielbares Frontend-Demo mit 4 Original-Spielen, Provably-Fair-Engine, VIP-System und Gamification — aber **ohne echtes Backend, Payment oder Server-Validierung.**

**Chance:** Der Markt ist gesättigt mit großen Anbietern, aber unterversorgt mit hochpolierter, modularer Open-Source-Infrastruktur und Web3-nativen Mechaniken. Die Lücke zwischen Demo und Production-Grade ist unser Hebel.

### 🏗️ Phase 1 — Fundament (Big Levers)
> Ohne diese Punkte ist kein Production-Betrieb möglich

- [ ] **[P1-01] Backend & Datenbankinfrastruktur aufbauen**
  - [ ] PostgreSQL / Supabase Setup für User-Daten, Bet-History, Balances
  - [ ] Prisma ORM Schema: User, Wallet, Bet, GameSession, Transaction
  - [ ] Server-Actions / tRPC-Routen für alle Spiele-Endpunkte

- [ ] **[P1-02] Authentifizierung hardnen**
  - [ ] Clerk User-Profile mit echten Rollen (Player, VIP, Admin)
  - [ ] Server-seitige Session-Validierung bei allen Bet-Requests
  - [ ] CSRF-Schutz in Middleware reaktivieren (aktuell deaktiviert!)
  - [ ] Rate-Limiting auf alle `/api/casino/*` Routen

- [ ] **[P1-03] Provably Fair — Server-Seite**
  - [ ] Server-Seed wird serverseitig generiert & nur Hash an Client
  - [ ] Game-Results server-seitig validiert (nie client-trusted)
  - [ ] Seed-Rotation API mit On-Chain-Hash-Ankündigung

- [ ] **[P1-04] Crypto-Payment-Integration (Minimum Viable)**
  - [ ] USDT / USDC Stablecoin Deposit (ERC-20, TRC-20)
  - [ ] Bitcoin Deposit via Lightning Network
  - [ ] Ethereum Deposit
  - [ ] Withdrawal-Queue mit manueller Admin-Freigabe (sicher starten)
  - [ ] On-chain Confirmation-Tracking (2-block Minimum)

- [ ] **[P1-05] Wallet-System (echtes Backend)**
  - [ ] Atomic Balance-Operationen (kein Double-Spend möglich)
  - [ ] Cent-genaue Integer-Arithmetik (kein Float für Geldbeträge!)
  - [ ] Deposit / Withdrawal / Bet als atomare DB-Transaktionen
  - [ ] Rollback bei Spielfehler

- [ ] **[P1-06] Admin-Panel funktionsfähig machen**
  - [ ] Echtzeit-Statistiken (Wagered, GGR, Active Users) aus DB
  - [ ] Player Management (Sperren, Limits setzen, VIP zuweisen)
  - [ ] Transaction-Logs mit Filterung
  - [ ] Responsible Gaming Alerts (echte Durchsetzung)
